# Cartão de Perfil

Projeto desenvolvido com HTML e CSS com o objetivo de praticar conceitos de desenvolvimento front-end e design de interfaces.

## Objetivo

Criar uma interface simples e moderna para exibição de informações de um usuário, aplicando boas práticas de estruturação e estilização.

## Tecnologias Utilizadas

- HTML5
- CSS3

## Funcionalidades

- Exibição de informações do perfil
- Layout limpo e organizado
- Design responsivo
- Estrutura semântica em HTML

## Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos como:

- Estruturação de páginas com HTML
- Estilização com CSS
- Organização de componentes visuais
- Responsividade
- Boas práticas de desenvolvimento front-end
